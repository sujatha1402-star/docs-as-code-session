## What is GTS Ethernet Hard IP?

GTS Ethernet Hard IP is a configurable Ethernet IP core
for Agilex 5 FPGAs and SoCs.

It provides Ethernet functionality using hardened
hardware blocks to support data transmission and reception.

### Key Components

| Component | Description |
| --- | --- |
| MAC | Handles Ethernet frame transmission and reception. |
| PCS | Performs physical coding functions. |
| PMA | Supports the physical serial interface. |
| FEC | Provides optional forward error correction. |

:::tip
If you are new to Ethernet IP, begin with the Getting
Started section before exploring configuration and simulation.
:::
