# Device Support

Before configuring Ethernet Hard IP, review the supported FPGA devices and applicable device requirements.

## Overview

Device compatibility is an important consideration when planning an FPGA Ethernet IP design.

## What to check

- Target FPGA device and family
- Applicable device speed grade
- Ethernet Hard IP support
- Supported configuration options

## Reference documentation

For device-specific support information, refer to the [GTS Ethernet Hard IP User Guide for Agilex 5 FPGAs and SoCs](https://docs.altera.com/r/docs/817676/26.1.1/gts-ethernethard-ip-user-guide-agilex-5-fpgas-and-socs/device-speed-grade-support).
