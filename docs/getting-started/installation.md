# Install GTS Ethernet Hard IP

## Objective

Learn where to find GTS Ethernet Hard IP after installing Quartus Prime Pro Edition.

## Before You Begin

Ensure that you have installed a compatible version of Quartus Prime Pro Edition for your target Agilex 5 device.

:::note
The Quartus Prime Pro Edition installation includes an IP library containing GTS Ethernet Hard IP. Consult the official Altera documentation for current software and licensing requirements.
:::

## Locate the IP Library

Quartus Prime installs IP cores in the following default directories.

| Operating System | Default IP Library Location |
| --- | --- |
| Windows | `C:\altera_pro\<version>\ip\altera` |
| Linux | `<home_directory>/altera_pro/<version>/ip/altera` |

Replace `<version>` with your installed Quartus Prime version.

## Next Steps

After locating the IP library, continue to **Configure GTS Ethernet IP** to learn how to create and configure an IP variation.
