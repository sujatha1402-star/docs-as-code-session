# Prerequisites

Before configuring Ethernet Hard IP, review the requirements for your target FPGA design.

## Required information

- Target FPGA device and speed grade
- Applicable Ethernet Hard IP user guide
- Required development tools and supported versions
- Intended Ethernet interface configuration
- Simulation and verification requirements

## Before you begin

1. Confirm that your target FPGA device supports the intended Ethernet Hard IP configuration.
2. Review the applicable product documentation.
3. Identify the development and simulation tools required for your design.
4. Prepare the project information needed for IP configuration.

## Next steps

After reviewing these prerequisites, proceed to Ethernet Hard IP configuration.
