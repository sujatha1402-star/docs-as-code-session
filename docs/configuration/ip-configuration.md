# Configure Ethernet IP

This guide outlines the general steps for configuring
GTS Ethernet Hard IP in an FPGA design.

## Before you begin

- Identify the target FPGA device and speed grade.
- Review the supported Ethernet IP configurations.
- Confirm the required development tools are available.
- Review the applicable Ethernet IP user guide.

## Configuration workflow

1. Create or open an FPGA project.
2. Select the Ethernet IP component supported by the device.
3. Review the available IP configuration parameters.
4. Configure the required Ethernet interface options.
5. Generate the IP design files.
6. Review the generated files and configuration messages.

## Next steps

After configuring the Ethernet IP, follow the applicable
product documentation to simulate and verify the design.

:::note
This is a general example. Exact parameters and procedures
depend on the FPGA device and IP version.
:::
